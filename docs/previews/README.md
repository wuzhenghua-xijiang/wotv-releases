# 预览图片

图片来自沃TV的 Flutter 界面组件，按对应平台能力、窗口尺寸和主题生成，使用示例内容；用于展示应用布局，不代表系统桌面或原生播放器的实机截图。

| 文件前缀 | 平台布局 | 尺寸 |
| --- | --- | --- |
| `android` | Android 手机 | 390 × 844 |
| `android-tv` | Android TV，包含遥控器焦点 | 1280 × 720 |
| `ios` | iPhone | 390 × 844 |
| `ipados` | iPad | 834 × 1194 |
| `macos` | macOS 桌面 | 1440 × 900 |
| `windows` | Windows 桌面 | 1440 × 900 |

每个平台包含 `<平台>-light-home.png`、`<平台>-dark-home.png` 两张首页预览。替换同名图片即可更新仓库首页，无需修改图片链接。

`wotv.png` 为应用图标。
